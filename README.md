# ai-roadmap

42 周 AI 学习路线的代码记录。按周推进，每天收工一次 commit。

## 目录

- `第一章/` — Python 基础语法：变量、运算符、分支、循环、20 道基础题（P1–35）
- `第二章数据容器/` — 容器与函数：list / str / tuple / set / dict、函数（P36–68）

## 运行方式

每个 `.py` 都保留随堂手写稿原貌（注释形式），末尾追加「可运行验证版」，可直接运行：

```bash
python 文件名.py
```

系统整理的复习笔记放在 Obsidian 库（`one drive/Python/`），按 `第NN章-NN 标题.md` 命名，与这里的脚本一一对应。
